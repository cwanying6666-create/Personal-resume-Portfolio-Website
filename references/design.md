# 个人作品集网站视觉规范

本文档只负责规范网站的视觉风格、布局、组件、动效和响应式规则。内容采集、用户问题、项目资料、工作经历、教育经历和联系方式的询问方式，请使用 `content-prompt.md`。

生成或修改网站时，视觉风格、色彩系统、字体系统、布局节奏和组件样式必须直接遵循本文档，不再向用户询问视觉偏好或配色偏好。

## 1. 设计定位

网站定位为面向求职和专业展示的个人作品集网站，适合产品设计师、UX 设计师、UI 设计师、交互设计师等创意与体验岗位。

整体气质：

- 暗色高级
- 强排版
- 专业克制
- 带一点未来感和发光感
- 像成熟设计师作品集，而不是普通简历页
- 像作品展示界面，而不是营销落地页

设计重点：

- 第一屏要快速建立个人身份与职业感
- 项目区要成为视觉重心
- 经历区要清晰可信
- 联系区要直接、稳定、易读
- 动效服务阅读，不制造干扰

避免：

- 通用模板感
- 过度商务化
- 可爱风、插画风、卡通风
- 大面积紫色渐变
- 无意义装饰图形
- 普通博客式布局

## 2. 色彩系统

默认使用固定色彩系统，不询问用户。

基础色：

- Ink / 主背景：`#0C0C0C`
- Mist / 主文字：`#D7E2EA`
- Steel / 深灰辅助：`#646973`
- Ice / 浅灰标题：`#BBCCD7`

强调色：

- Deep Purple：`#18011F`
- Magenta：`#B600A8`
- Violet：`#7621B0`
- Warm Orange：`#BE4C00`
- Electric Blue：`#2D9CFF`

使用规则：

- 页面主背景使用 `#0C0C0C`。
- 深色背景上的主文字使用 `#D7E2EA`。
- 次级文字使用 `rgba(215, 226, 234, 0.45)` 到 `rgba(215, 226, 234, 0.76)`。
- 大标题可使用冷灰渐变：`#646973` 到 `#BBCCD7`。
- 紫粉橙渐变只用于 CTA、当前导航、高亮和少量发光。
- 蓝色只用于少量视觉作品卡片边框或强调，不作为主色。
- 浅色区块只用于制造节奏反差，例如能力区。

禁止：

- 将页面做成单一紫色主题
- 使用大面积彩虹渐变
- 使用米色、棕色、咖啡色作为主视觉
- 使用过亮的纯白背景贯穿全站

## 3. 字体系统

默认字体：

```css
font-family: 'Kanit', 'Noto Sans SC', system-ui, sans-serif;
```

字体使用：

- 英文大标题使用 Kanit，强调力量感和几何感。
- 中文正文使用 Noto Sans SC，保证阅读舒适。
- 大标题使用粗字重，建议 `800-900`。
- 中文正文使用 `300-500`。
- 不使用负字距。
- 大标题不随视口宽度线性缩放，使用 `clamp()` 控制上下限。

推荐字号：

- 首页英文身份标题：`clamp(4.2rem, 9vw, 8rem)`
- 一级区块标题：`clamp(3rem, 10vw-12vw, 150px-160px)`
- 经历区大标题：`clamp(3rem, 9vw, 130px)`
- 项目名称：`clamp(2rem, 4vw, 3rem)`
- 卡片标题：`1.5rem-2rem`
- 正文：`1rem-1.125rem`
- 元信息：`0.75rem-0.875rem`

行高：

- 大标题：`0.9-1.08`
- 中文正文：`1.75-2`
- 卡片短文本：`1.5-1.7`

## 4. 页面结构

网站为单页纵向滚动结构，并允许项目详情页或详情状态。

固定模块顺序：

1. 顶部导航
2. Resume / 个人介绍
3. Project / 项目展示
4. Ability / 能力
5. Experience / 工作与教育经历
6. Others Project / 其他内容
7. Contact / 联系方式

布局规则：

- 每个主区块使用整宽背景。
- 内容容器宽度优先使用 `max-w-6xl` 或 `max-w-7xl`。
- 页面横向内边距使用 `px-5 sm:px-8 md:px-10`。
- 主区块纵向内边距使用 `py-20` 到 `py-32`。
- 深浅背景切换时可以使用顶部大圆角过渡。
- 不在页面区块外额外套装饰卡片。
- 不把卡片嵌套在卡片里。

## 6. 顶部导航

导航固定在页面顶部。

结构：

- 左侧：中文名或个人品牌名
- 中间：导航链接
- 右侧：联系按钮

导航项：

- Resume
- Project
- Ability
- Experience
- Others Project
- Contact

视觉：

- 背景：深色半透明
- 模糊：`backdrop-blur-xl`
- 底部分割线：`border-mist/10`
- 阴影：深色大阴影
- 高度保持稳定，不随页面内容变化

当前导航：

- 使用紫粉渐变文字
- 允许轻微发光
- 非当前项保持浅灰文字

移动端：

- 可隐藏中间导航，只保留姓名和联系按钮
- 不允许文字拥挤或换行重叠

## 7. 个人介绍区

个人介绍区是第一屏核心。

视觉要求：

- 使用大字号英文标题展示个人身份。
- 个人照片或头像与标题形成层叠关系。
- 标签使用半透明玻璃质感。
- 基础信息使用小卡片承载。
- 整体保持居中、强视觉、少解释文字。

组件规则：

- 头像使用 `object-contain`。
- 标签使用圆角胶囊形、半透明背景、浅色边框。
- 信息卡片使用半透明背景和轻微模糊。
- 联系按钮使用主 CTA 样式。

## 8. 项目区

项目区是网站视觉重心。

标题：

- 上方小字：`My Latest Projects`
- 主标题：`PROJECT`
- 主标题使用超大冷灰渐变文字

项目卡片：

- 纵向堆叠
- 大编号：`01`、`02`、`03`
- 元信息：项目类型 / 项目时间
- 项目名称
- `View Project` 按钮
- 悬停展开封面图
- 展开区域使用 `max-h-[780px]` 作为动画上限，避免压缩 16:9 封面

卡片视觉：

- 深色背景
- 浅色粗边框
- 大圆角
- 轻微叠放
- 当前 hover 卡片上移
- 非当前卡片轻微变暗

封面图：

- 使用本地图片路径，例如 `/project1.jpg`
- 项目模块里的每个项目封面必须统一使用 16:9 比例
- 使用外层固定比例容器：`aspect-[16/9] w-full`
- 图片在容器内使用 `h-full w-full object-cover`
- 当前实现从顶部开始裁切，使用 `object-top`
- 不要给 16:9 封面容器设置额外 `max-height`，避免在窄屏或展开动画中压缩比例
- 不拉伸、不变形
- 项目卡片悬停展开封面和项目详情页顶部封面都必须遵循 16:9
- 用户上传的封面如果不是 16:9，也必须按 16:9 容器裁切展示，不能改变卡片比例

## 9. 项目详情页

项目详情页或详情状态用于展示用户上传的 PDF 作品内容。

视觉要求：

- 详情页背景保持深色。
- 顶部有返回项目列表按钮。
- 项目详情页顶部项目封面必须使用 16:9 比例容器。
- PDF 内容应以清晰、稳定、可阅读的方式展示。
- 如果将 PDF 转为图片预览，每页图片保持等宽排列。
- 图片或页面预览必须有足够圆角、边框或间距。
- 不把 PDF 页面塞进过小的卡片里。

推荐布局：

- 返回按钮
- 项目标题和基本信息
- PDF 页面预览纵向排列
- 移动端保持单列

## 10. 能力区

能力区使用浅色背景制造节奏反差。

视觉：

- 背景：白色或浅色
- 文字：`#0C0C0C`
- 标题：巨大黑色 uppercase
- 内容：两列布局，移动端单列

能力条：

- 使用横向进度条
- 背景为浅灰
- 填充为 Ink
- 进入视口时从 0 动画到目标值

## 11. 经历区

经历区使用深色背景。

布局：

- 桌面端左侧为工作经历
- 右侧为教育经历卡片
- 移动端上下堆叠

工作经历：

- 每条经历用顶部细分割线区分
- 时间使用小号元信息
- 职位使用较大粗体中文
- 公司使用次级浅灰文字
- 描述使用舒适行高

教育经历：

- 使用半透明卡片
- 标题为 `Education`
- 学校条目用分割线区分
- 学校名称要清晰突出

## 12. 其他内容区

其他内容区采用瀑布流或多列布局。

卡片类型：

- 推荐语卡片
- 视觉作品卡片
- 设计思考卡片
- 当前页面也兼容设计随笔卡片

视觉规则：

- 卡片使用深色半透明背景
- 边框轻
- 圆角统一
- hover 可轻微上浮
- 视觉作品卡片可以使用局部渐变背景，但必须服务图片展示
- 推荐语卡片使用大段文字和底部推荐人信息，不放图片

禁止：

- 过度装饰
- 过密排版
- 无图片却伪装成视觉作品

## 13. 联系区

联系区保持直接、稳定、易读。

结构：

- 大标题：`CONTACT ME`
- 三张联系方式卡片：电话、微信、邮箱
- 底部版权和城市

图标：

- 电话使用 lucide `Phone`
- 邮箱使用 lucide `Mail`
- 位置使用 lucide `MapPin`
- 微信直接使用 `/wx.svg`
- 微信图标不询问用户，默认嵌入网站

微信图标样式：

- 使用 `img`
- 尺寸：`28px`
- 透明度：`0.7`
- 与其他联系图标保持同一视觉层级

## 14. 按钮规范

主按钮：

- 胶囊圆角
- 白色文字
- 白色描边
- 紫粉橙渐变背景
- 轻微发光
- hover 缩放约 `1.03`

次级按钮：

- 胶囊圆角
- 透明背景
- 浅色边框
- 搭配 ArrowUpRight 图标
- hover 时轻微浅色背景

## 15. 动效规范

动效应克制。

允许：

- 滚动进入渐入
- 轻微位移进入
- 项目卡片 hover 展开
- CTA hover 缩放
- 进度条进入视口动画
- 少量磁吸按钮效果

默认参数：

- 初始透明度：`0`
- 进入透明度：`1`
- 位移：`y: 30 -> 0`
- 持续时间：`0.7s`
- 缓动：`[0.25, 0.1, 0.25, 1]`

禁止：

- 大幅弹跳
- 长时间循环动画
- 影响阅读的滚动劫持
- hover 导致布局大幅跳动

## 16. 纹理和光效

可以使用固定细颗粒纹理增强质感。

推荐 CSS：

```css
.grain {
  pointer-events: none;
  position: fixed;
  inset: 0;
  z-index: 50;
  opacity: 0.12;
  mix-blend-mode: soft-light;
  background-image:
    radial-gradient(circle at 1px 1px, rgba(255, 255, 255, 0.32) 1px, transparent 0);
  background-size: 22px 22px;
}
```

规则：

- 纹理必须非常轻。
- 光效只用于 CTA、当前导航或重点视觉区。
- 不使用随机漂浮装饰球。

- 项目封面使用用户提供的图片。
- 微信图标固定使用 `/wx.svg`。
- 用户上传的 PDF 用于项目详情页内容。
- 有意义图片必须写 alt。
- 装饰图可使用空 alt 和 `aria-hidden`。

## 18. 响应式规范

桌面端：

- 导航完整展示
- 项目卡片横向组织标题和按钮
- 经历区左右两列
- 其他内容区三列瀑布流

移动端：

- 内容自然单列
- 大标题用 `clamp()` 保持不溢出

- 卡片宽度必须适配屏幕
- 按钮文字不能挤压或溢出
